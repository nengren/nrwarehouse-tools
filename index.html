称重排除 SKU Excluded from weight check

一行一个。按开头匹配、不分大小写：填 IN- 会排除 in-10mm-d、IN-20MM-W 等。包裹里只要有一个被排除的 SKU，整个包裹不参与称重校验；产量照常统计。
One per line. Matches the start of the SKU, case-insensitive: IN- excludes in-10mm-d, IN-20MM-W… A parcel with any excluded SKU is skipped in weight check; output still counts it. Use * as wildcard, e.g. *SEAWEED*.
